How the AI was built

1 · DataPhysical model

Thousands of healthy-operation measurements: heating follows the square of the current, vibration follows the load.

2 · TrainingPython + NumPy

The 4→16→16→1 network learns to tell normal data apart from randomly drawn measurements. It learns the shape of the healthy zone.

3 · ExportEmbedded C code

The weights become a C array. Inference is hand-written and checked against Python to within 0.001.

4 · DecisionOn the ESP32

Debouncing over 3 measurements, probable cause explained, alert sent to the dashboard and to Telegram.
